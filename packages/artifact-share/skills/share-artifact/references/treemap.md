# treemap

Mermaid's documentation examples, from Pele 1.13.0's test corpus; each renders on the site. Written by `pnpm run vendor-artifact-share` in opencode-office; don't edit.

```mermaid
treemap-beta
"Category A"
    "Item A1": 10
    "Item A2": 20
"Category B"
    "Item B1": 15
    "Item B2": 25
```
